# Project Overview
The Spotify Searchinator utilizes the Spotify Web API to allow users to search for songs, artists, and albums. The project has user-friendly front-end and a backend that serves the front-end and handles user authentification.

## Tech Utilized
- React + Vite for the front-end
- TailwindCSS for front-end styling
- Express for the backend

# Prerequisites
NodeJS >= 20.18.0  
npm >= 10.8.2  

# Getting Started
To run the server, change directory into the backend folder and then use `npm run start` in the terminal. This will start the server on port 3000 unless specified otherwise in the environment variable, `PORT`.

To run the front-end, change directory into the frontend folder and use npm run dev, this will run a server hosted on port 5173.
